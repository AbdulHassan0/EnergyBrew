# EnergyBrew frontend (research preview)

The frontend is live-code HTML, CSS and JavaScript with **zero npm dependencies**. It uses the actual research desk generated by EnergyBrew's hosted collectors. It is **not** a production newsletter or a fact-checked news publisher.

## See it instantly
- Download the energybrew-frontend-preview artifact from the latest **EnergyBrew frontend preview** Actions run.
- Extract the ZIP and serve it locally (from the extracted folder):
    python -m http.server 8000
- Open http://localhost:8000/ in your browser.
- The committed frontend/data/feed.json is a real timestamped fallback research snapshot, not invented news. It becomes stale; hosted builds regenerate from the collector-state branch.

## Deploy to a browser URL
1. Open https://github.com/AbdulHassan0/EnergyBrew/settings/pages.
2. Under **Build and deployment**, change **Source** to **GitHub Actions**. Note: GitHub Pages on a private repository requires GitHub Pro, Team or Enterprise. GitHub Pages output can be publicly accessible even if the repository is private.
3. Open https://github.com/AbdulHassan0/EnergyBrew/actions/workflows/site-preview.yml and select **Run workflow**.
4. Once successful, the expected site URL is https://abdulhassan0.github.io/EnergyBrew/ (not confirmed live until Pages is enabled and deployment succeeds).
5. The static snapshot is scheduled to refresh every two hours, subject to GitHub Actions delays.

## Local rebuild from current collector state
From the repo root, download these three JSON files from the private collector-state/state/ branch into latest-state/: desk_latest.json, metrics_latest.json, health_latest.json.

    python site_builder.py --desk latest-state/desk_latest.json --metrics latest-state/metrics_latest.json --health latest-state/health_latest.json --out dist
    python -m http.server 8000 --directory dist

## Included
- Original mobile-friendly editorial design, filter/search/saved article UX
- Real original-source links and source provenance labels
- Topic coverage metrics, collection activity indicator
- Zero fake articles or summaries; failure is explicit
- Site builder whitelists research metadata and strips internal collection state

## Not yet included
Subscriber accounts, emails, newsletter archives, source licensing or independent fact verification, automatic summarization, analytics and editorial approval workflow.

Research candidate titles/links may be subject to source-specific rights. Do not operate as a commercial publication without reviewing permitted use and editorial claims.
